# Data notes

`sample/invoices_sample.csv` contains 100 records for quick review. `raw/invoices_raw.csv` is generated by `src/generate_data.py` and is excluded from Git to keep the repository compact.

The data represents fictional invoices created for portfolio practice. Dates, suppliers, invoice values, and payment statuses are synthetic. The generator uses a fixed random seed for reproducible results.

`processed/invoices_clean.csv` is created by `src/analyze_invoices.py` and contains calculated fields for payment days, overdue status, aging, late payments, and duplicate candidates.
