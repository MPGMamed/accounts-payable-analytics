# Outputs

The analysis script creates tables for direct Power BI import and two charts for the project README.

| File | Purpose |
| --- | --- |
| `tables/kpi_summary.csv` | Main accounts-payable KPIs |
| `tables/supplier_summary.csv` | Supplier invoice and overdue exposure |
| `tables/department_summary.csv` | Department spend summary |
| `tables/aging_summary.csv` | Outstanding invoice aging |
| `charts/top_suppliers.svg` | Top supplier spend chart |
| `charts/overdue_aging.svg` | Overdue exposure by aging bucket |
